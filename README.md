# Tip Tracker V2 (tracker-os-v3)

Modern server tip ledger.

- Log shifts with tips, hours, sales, and notes  
- Weekly totals, all-time totals, and avg/hour  
- Weekly trend + best-day + shift-type charts  
- Export your data as CSV  
- Runs fully in the browser (localStorage)

## Deployed at

https://tracker-os-v3.vercel.app

## Tech

- Static site on Vercel  
- No backend, all data in localStorage  
- Modern dark UI with cohesive design system
